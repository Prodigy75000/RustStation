# docs/ref/

Drop the raw hardware reference material here. **Nothing in this folder is
committed** except this file: third-party manuals and reference sites are not
ours to redistribute, even when they are freely available.

What belongs here:

- The MIPS R3000 / R3000A architecture and instruction set manuals.
- The LSI CW33300 core documentation, where it differs from stock R3000.
- Console hardware references covering the GPU, SPU, CD-ROM, DMA, timers, the
  GTE and the BIOS function tables.
- Anything else that describes *the hardware*. Not another emulator's source.

What comes out of here goes into [`../notes/`](../notes/) in our own words,
and the implementation is written from the note. See
[`../README.md`](../README.md) for why that order matters.

Cite what a note came from, by document and section, at the top of the note.
